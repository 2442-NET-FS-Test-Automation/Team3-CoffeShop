# Coffe Shop Test Cases
### For the correct functionality in this project we need to cover this requirements:

|   Id   |                           Requirement                            | Value | Status  |
| ------ | ---------------------------------------------------------------- | ----- | ------- |
| Req-01 | Add a new product in the menu to be chosen in orders             | Must  |         |
| Req-02 | Change price and name of each product and delete unused products | Must  |         |
| Req-03 | Change quantity in each product (sum and substract)              | Must  |         | 
| Req-04 | See reports for sales (total, highest, average) in the same page | Must  |         |
| Req-05 | Select products in stock to put them in the same order           | Must  |         |
| Req-06 | Deliver the order while the stock and products let it            | Must  |         |

We need to verify the **correct behaivor using unit, integration and end-to-end test cases** in this application
**Each requirement will we covered in one test individually** for secure correct behaivor
Extra tests can involve more that one requirement **if the path is logical and a common operation to user**
The nomenclature to name test cases is this : **TCQ-TestNumber (if the number has only one digit will be write like 0X)**
